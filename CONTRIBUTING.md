# Участие в MaxWave

Форки и pull request приветствуются. Создайте форк, отдельную ветку и PR в `main` с описанием проблемы, изменения и проверки. Для ошибки приложите модель станции, сборку Android, версии приложений и обезличенный фрагмент журнала. Не публикуйте подписки VPN, токены, пароли и данные аккаунтов.

Проверенная аппаратная база — YNDX-00053 / 5000000921 с уже полученным постоянным root. Поддержку другой модели или версии нужно подтверждать отдельно. Указывайте, проверялось ли изменение на реальной станции; прохождение тестов кода не означает проверку голоса, звука или перезагрузки.

Локальные проверки:

```sh
python -m unittest discover -s tests -v
node bridge/test-core.js
cd native
go test -race ./...
```

Контроллер Go предназначен для Android ARM64; его тесты запускаются на Linux/macOS. Windows проверяет установщик, маршрутизатор команд и стартовый файл. APK и готовые ARM64-компоненты распространяются через релизы и не добавляются в Git. Личные настройки `.station`, кеши, аккаунты и signing keys также не коммитьте.

Не добавляйте обработку музыки на компьютер: после установки станция должна работать самостоятельно. Настройки VPN должны охватывать только YouTube Music, сохраняя прямой доступ Алисы и системных служб. Изменения прошивки, получение root и снятие защиты OTA не относятся к установщику музыкального сервиса.
