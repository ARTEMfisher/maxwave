# Проверки автономной версии 0.2.0

На YNDX-00053 / Android 9 / 5000000921 с постоянным mysudo/root 30 октября 2026 года проверены установка локальных компонентов, сохранение исходного root-скрипта и добавление только блока MaxWave, самостоятельный старт после перезагрузки и восстановление подключений к Алисе и плееру. При отключённом ADB и остановленном процессе прототипа на Mac пользователь подтвердил запуск трека в YouTube Music, паузу и продолжение.

Happ после одного холодного запуска создал туннель без рабочего DNS. Переподключение восстановило реальные HTTPS-запросы от UID YouTube Music и SDK. Затем включён режим только для YouTube Music: Android подтвердил единственный UID 10018; Алиса и остальные приложения выходят напрямую. Автоматическая смена серверов VPN и восстановление неисправного узла не реализованы. Длительный тест VPN после многочисленных перезапусков не проведён.

В автономном HTTP-клиенте проверены поиск трека, альбома Mutter с очередью, коллекции исполнителя, настроения Energize и полной загрузки стороннего канала. Поиск на станции выполняется от UID плеера. Это метаданные каталога, не скачивание аудиофайлов.

В прототипе пользователь подтвердил перемотку, быстрый стоп, предыдущий трек, личный Supermix, энергичную музыку, переключатель видео/аудио, объявление названия и оценки. Эти обработчики перенесены в автономную версию; все они ещё не прошли повторную голосовую проверку после переноса. Короткий «следующий» остаётся ненадёжным, «далее» без обращения отсутствует в словаре модели. Новый локальный голос eSpeak механический; WAV генерировался на станции, качество произношения не считается исправленным.

Проверки кода: Python — конфигурация, адреса, checksum, безопасная распаковка, root/firmware gates, политика VPN, allowlist архива и сохранение ранее установленных приложений при экспериментальном откате. Go — выбор коллекции исполнителя, отбор полного альбома канала, обработка пустого каталога и ошибок HTTP; race detector. JavaScript — классификация музыкальных и бытовых фраз, ASR final state, дедупликация, перемотка и остальные маршруты. Проверяются синтаксис стартовых файлов и приватность содержимого релиза.

Полная установка на чистой станции, длительная надёжность, реальный запуск установщика на Windows/Linux и физический откат на обычную музыку не проверены. Откат помечен экспериментальным и плохо протестированным. CI не проверяет звук или физический Android.


## Необязательное управление по SSH

Автоматические unit-тесты находятся в `tests/test_ssh.py` и запускаются вместе с остальными проверками:

```sh
python -m unittest discover -s tests -v
```

Они проверяют валидацию host/port/username/identity file, отказ от публичных ключей и PPK, безопасные параметры OpenSSH, строгую проверку host key, отключение парольной аутентификации, передачу команд через stdin, обработку ошибок аутентификации, проверку UID 0 и использование штатных скриптов MaxWave.

Физическая проверка требует уже настроенного SSH-сервера, доверенного host key, приватного ключа и root-аккаунта. MaxWave не включает сервер и не меняет его конфигурацию. Реальное подключение нужно отдельно проверить на конкретной станции. Перед использованием сначала выполните проверку подключения и UID 0, затем проверку состояния и скриптов. Команды запуска, остановки и перезапуска применяйте только после проверки текущего статуса.

ADB-путь установки, передачи файлов и scrcpy остаётся отдельным и не заменяется SSH.
