# Проверки и статус

## Подтверждено на реальной станции

YNDX-00053, Android 9 / 5000000921, постоянный mysudo/root, macOS ARM64:

- YouTube Music ReVanced Extended 8.12.54 с GmsCore, Happ и scrcpy software VP8.
- Финальное распознавание Алисы, дедупликация, команды музыкального поиска, исполнитель/трек/альбом.
- Переход с первого на второй трек альбома Mutter.
- Полная альбомная загрузка YouTube-канала.
- Пауза, продолжение, относительная перемотка ±30 секунд, назад/дальше.
- Быстрые стоп/играй/назад; быстрый следующий остаётся ненадёжным, далее отсутствует в модели.
- Личный Supermix и энергичная подборка; Sad/Chill проверены через API.
- Переключение видео/аудио, объявление текущего названия, оценки.

Эти живые проверки сделаны на рабочем прототипе, из которого выделен репозиторий. Полный новый установщик/откат на чистой станции и все сочетания Windows/Linux не проходили длительного физического тестирования.

## Проверки пакета

- Python unit tests: адреса/платформы, пути, checksum, безопасная распаковка, root/firmware gates, откат без удаления прежних приложений, dry-run без изменений, allowlist релизных файлов.
- JavaScript: бытовые исключения, собственно музыкальные запросы, ASR final state, дедупликация, перемотка, быстрые варианты, потоки, видео/аудио, информация и оценки.
- Регрессионный тест: «твоим» не считается аббревиатурой «тв».
- CI: Windows, Linux, macOS; Python/Node tests и синтаксис стартовых файлов. Реальный звук и Android через CI не проверяются.
- Скачивание и извлечение официальных desktop archives с SHA256 проверены локально для Mac ARM64/Intel, Windows x64/ARM64 и Linux x64. Это не означает исполнение всех чужих бинарников на их платформах.

## Перед использованием на другом устройстве

Проверьте этикетку 00053, свой root и ADB, совместимую сборку, воспроизведение вручную, доступность домашней сети при VPN и интернет компьютера. Диагностику запускайте цифрами; она не меняет роутер или VPN. Публикуя результаты, удаляйте IP, названия сетей, ссылки подписок и приватные данные из журналов.

Откат помечен экспериментальным. Не считайте его способом вернуть заводскую прошивку или отменить root, блокировки OTA и настройки, внесённые до MaxWave.
